# Agent guide

Instructions for AI coding agents working in this repository. Read [README.md](README.md) for the project overview and [Research.md](Research.md) for the research plan and current progress.

## Project in one paragraph

A university data science project (Data3001) that builds a surface-transport operator for the Agulhas region, box R = 10–55°E, 45–15°S (scored on data, shipping risk and retention in `box_selection`). NOAA Global Drifter Program tracks are binned on a grid (0.5°, 1° and 2°), and cell-to-cell moves over a lag τ (default 3.5 days) are counted into a row-stochastic transition matrix (Ulam's method). Two versions are tracked side by side: drogued drifters (15 m current, passive transport) and undrogued drifters (surface current plus about 2% windage, the closer match to oil), and an oil matrix built from undrogued moves shifted by the missing windage (`oil_wind`). Never pool them into an "all drifters" matrix. The matrices are iterated to answer where material released at a point is after 1 week, 1 month and 1 year, and to analyse where R gathers and loses material.

## Environment

- Use the project virtual environment: `.venv/bin/python` (Python 3.9).
- `python -m agulhas all` runs every step in order (`--from`, and `--box` with `--data` for another region); `python -m agulhas list` prints the steps and `python -m agulhas <step>` runs one. Run these **from the repository root**; steps use relative paths (`data/...`, `figures/...`), and import `agulhas.config` and `agulhas.transport`. `python -m pytest` runs the tests, which need no data.
- The Python is built against LibreSSL, so urllib3 prints a `NotOpenSSLWarning`; it is harmless. Pass `-W ignore` for cleaner output.
- Dependencies are pinned in `requirements.txt`. `zarr` stays on 2.x (`zarr.open_group` on an `FSStore` over HTTPS). Do not upgrade to zarr 3 without checking `agulhas/sources/fetch_gdp_subset.py`.
- No dask is installed and the machine has 8 GB RAM. Never load the full global GDP arrays (197M observations) into memory; stream them chunk by chunk as `fetch_gdp_subset` does.

## Data rules

- The data source is the GDP hourly zarr store on AWS S3 (`gdp1h`), subset by `fetch_gdp_subset` into `data/agulhas_gdp1h_subset.nc` at the native **hourly** resolution (positions interpolated across > 6 h between satellite fixes are dropped; `gap` is kept). `fetch_gdp_subset` reads through an `FSStore` with `exceptions=(KeyError,)` and retries each chunk: zarr's default store treats any `OSError` as a missing chunk and fills it with NaN, which silently drops that chunk's drifters. All later scripts read that file. Rerun `fetch_gdp_subset` only if the region or margin changes.
- The subset covers 5°W–65°E, 60–5°S: every candidate box from `box_selection` (search area 0–60°E, 55–10°S) plus a margin, so positions just after a drifter leaves a box are available. Changing the box within that area does not need a new fetch. Always re-apply the R mask in analysis. A box elsewhere needs its own subset (`00 --fetch-box … --out …`, about 10° of margin), passed to every step with `--data`; `parse_args` stops if the box is outside the data file. The Gulf Stream subset is `data/gulfstream_gdp1h_subset.nc`, for box 80–40°W, 25–45°N.
- The subset is sorted by (trajectory, time), and every time is on the hour. `transition_matrix` relies on this for pairing.
- `drogue_status` is boolean (True = drogued). A transition counts for a drogue type only if both ends have that status, except a move into the stranded state, which needs that status at its start only: the flag often flips to undrogued in a record's final hours, for groundings and other deaths alike, so the last fix does not show how the drifter reached the coast. Every matrix build filters moves with `transport.same_drogue`.
- Stranding comes from GDP's per-drifter `typedeath` (1 = ran aground) and `end_date`, kept in the subset by `fetch_gdp_subset`. `transport.strand_times` marks a drifter as stranded when its last observation is in R and within a day of `end_date`; `move_indices` then sends its final τ of positions to the stranded state. Other deaths (stopped transmitting, picked up) are missing data, not stranding. Most groundings are of drifters that lost their drogue long before (121 of 139; `drogue_loss`), so drogued stranding is a lower bound.
- Shipping traffic: World Bank / IMF "Global Shipping Traffic Density", Commercial layer (CC-BY 4.0), zip at `data/shipping/shipdensity_commercial.zip` (458 MB, 9.8 GB GeoTIFF inside). `shipping_overlay` reads the box straight from the zip with `rasterio` (`zip://…!/ShipDensity_Commercial1.tif`); never extract it. Values are undocumented in scale (bimodal: about 1–30 and 1e4–1e7 per pixel, far above plausible AIS counts; the high mode traces the lanes), and pixel coverage drops about 8-fold at exactly 40°S, a source artifact. Use them only as a relative density or ranking, never as counts.
- `data/` and `figures/` are gitignored, and so are `*.nc`, `*.zarr` and `*.csv`. Never commit data or figures.

## Code conventions

- Steps live in `agulhas/<topic>/<name>.py` and are referred to by name. A new step is a new module in its topic's folder, listed in `STEPS` in `agulhas/pipeline.py` after whatever it reads, with `agulhas_only=True` if it needs the Agulhas coasts, routes or winds. `agulhas/tools/worked_example.py` and `agulhas/tools/oil_explorer.py` only read pipeline outputs, so they are in `TOOLS` and a full run skips them.
- A module does nothing when imported. Its top level holds imports, constants and functions that stand alone; the run itself is `main(argv=None)`, which passes `argv` to `parse_args`, and the file ends with `if __name__ == "__main__": main()`.
- `shipping_overlay` picks candidate release points only in cells that are reliable in both the drogued and undrogued matrices (not `flagged`, not `empty`), so both versions are compared at the same points; hotspots in unreliable cells are moved to the nearest such cell and the shift is printed. Keep that rule for any new release points. Read them through `config.release_points_path(box)`, which gives the box's points picked at the default grid and lag, whatever grid and lag the reading step runs on.
- Each step starts with a docstring (title line "Agulhas Region — …", then what it does) and is split into numbered sections with headers such as `# ── 2. Pair each obs … ─────`.
- Plots use `matplotlib.use("Agg")`, cartopy with a plain-matplotlib fallback, and are saved to `figures/` at 150 dpi. Steps print a short summary and the saved paths.
- Region, grid, lag and data path live in `agulhas/config.py` (defaults: box 10–55°E, 45–15°S; grids 0.5°, 1°, 2°; τ = 3.5 d) and are overridden with `--box`, `--res`, `--tau` and `--data` (`parse_args`). Steps unpack them into `LON_MIN, LON_MAX, LAT_MIN, LAT_MAX`, `RES`, `TAU_DAYS`; the steps in `agulhas/whole_box/` loop over several grids with `multi=True`, and steps name their outputs with `setting_tag(res, tau, box)`, so runs at different settings never overwrite each other; do not hard-code them again. `fetch_gdp_subset` has its own padded fetch box (`--fetch-box`) and `box_selection` its own search settings. Anything written to a fixed name carries the box in that name, or follows the subset as `config.wind_paths` does for the ERA5 files. Print coordinates with `config.place_label`, so they read correctly in any hemisphere, and start figure names with `config.region_prefix(args.data)`, except in the Agulhas-only steps `box_selection` and `coastal_stranding`, `traffic_exposure` and `risk_atlas`.
- Use `grid_shape(box, res)` for the number of cells. If a box side is not a multiple of `res`, the last row/column is a partial cell clipped at the box edge (edges are clipped to the box).
- Grid cells use half-open intervals `[min, max)`, with index `j * n_lon + i`, where `j` is the latitude row from the box's southern edge and `i` the longitude column from its western edge.
- Use `agulhas/transport.py` (`load_operator`, `release`, `propagate`, `to_grid`, `coastal_states`, `cell_centres`, `reliable`, `absorption`) to work with saved matrices rather than re-implementing the logic. `absorption` gives each cell's expected steps in R and eventual fate exactly from the fundamental matrix; use it rather than iterating P for long-run results. On bootstrap resamples, which can leave a few thin cells with no way out, use `stranding_chain` instead, and keep every resample. Its building helpers (`strand_times`, `move_indices`, `transition_states`, `row_normalise`) are shared by `transition_matrix`, `bootstrap`, `oil_wind`, `held_out` and `trap_stability`; anything that builds a matrix uses them, so every build matches `transition_matrix` exactly. `drifter_counts` and `resampled_counts` redraw whole drifters for a bootstrap.
- `held_out`'s scores keep only starts whose outcome is known, which is fine to its 28-day horizon. Beyond that use `held_out_year`, which treats records that end early as censored; keeping only known fates over-counts exits.
- Uncertainty comes from `bootstrap`: resample whole drifters (never observations), with drogued and undrogued resampled independently. Report the 95% interval with any release-point number, and treat a single "differ" flag with care, since the intervals are not corrected for the number of points and metrics compared.

## Transition matrix format

Files are `data/P_{drogued|undrogued}_{res}deg_{tau}d_{box}.npz`, built by `config.operator_path` (e.g. `P_drogued_1deg_3p5d_10E-55E_45S-15S.npz`). Only read matrices through `operator_path`; any other `P_*.npz` in `data/` is not a pipeline output.

- `P` is (n_cells + 5) square: 975 × 975 at 1°, 3785 at 0.5°, 268 at 2° for the default box. The first `n_cells` states are ocean cells (`cell_flat` maps a state to its grid index); the last five are absorbing, in the order of `exit_labels`: exits `W, E, S, N` and `stranded` (`transport.STRANDED` is its offset after the ocean cells). Both drogue types share the same ocean cells. Read exits and stranding through `exit_labels`, never by assuming four exit columns.
- A row holds the probabilities of moving from that state to each state in one τ step. Distributions are row vectors, advanced with `p @ P`.
- `flagged` marks rows built from fewer than 10 distinct drifters, and `empty` marks cells with no outgoing moves of their own, whose rows pool the moves of the nearest ring of ocean cells (`row_normalise`). Mention both when reporting results for those cells. `bootstrap` adds a second check, `row_tvd_{drogued,undrogued}` in `data/bootstrap_rows_*.npz` (unstable if > 0.2). It understates the uncertainty of rows with only a few drifters, so the 10-drifter flag stays as the floor.
- Coast operators from `coastal_stranding` are `operator_path("{name}_coast", …)`: the same matrix with `stranded` split into six named coasts (`transport.COAST_LABELS`, defined for the Agulhas area by `coast_of`; `transport.check_coast_box` stops `coastal_stranding`, `traffic_exposure` and `risk_atlas` outside it), so they have n_cells + 10 states. The stranded state starts at the same `STRANDED` offset; read them through `exit_labels`.
- If τ, the grid or the region changes, the file name changes with it; always get paths from `operator_path`.

## Domain notes

- Drogued = passive water transport (little windage, e.g. a mostly submerged container). Undrogued drifters slip downwind by ~10 cm/s, measured as undrogued − drogued mean velocity per cell (`wind_slip`); against ERA5 winds that is 2.0% of the 10 m wind (`oil_wind`). Oil moves at current + 3.5% of wind speed, so `oil_wind` adds only the missing 1.5%. Do not add the full 3.5% wind on top of undrogued motion; that counts the wind twice. The oil matrices are `operator_path("oil", …)` and `operator_path("oil_check", …)` (drogued + 3.5%, a check only). `oil_3pct`, `oil_4pct`, `oil_check_3pct` and `oil_check_4pct` hold the rest of the 3–4% range (`config.OIL_WINDAGE_RANGE`); `oil` at 3.5% stays the headline. A release point where oil and its check differ by TVD > `config.DISAGREE_TVD` at 30 days is flagged as depending on the method.
- Pooling drogued and undrogued ("all drifters") gives a matrix whose wind effect varies with the local undrogued share (46–84% per cell), so it represents neither; do not use it.
- Oil mass loss is modelled as `m(t) = m0 · exp(−λt)`, with λ ≈ 1/14 per day as the working value.
- Velocity decorrelation time over the core region (10–40°E, 45–25°S) is about 1.4 days (drogued) and 1.2 days (undrogued; `decorrelation_time`), which is why τ = 3.5 days. Sensitivity checks use τ = 2 and 5 days.
- Expected behaviour for sanity checks: material released off Durban moves south-west along the coast. After a year (default box, 1°) about half has left R to the east (Return Current; 49% drogued, 56% undrogued), about a fifth to the west (leakage into the Atlantic), 17–18% is still in R and 6–11% has stranded.
